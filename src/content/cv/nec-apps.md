### Duty Statement

Train Associate Engineers in the Application Packaging team, maintain Work
Instructions, and be available as a Project Resource for Northern Territory
Government Projects. Automate Enterprise software deployment across all
agencies of the Northern Territory Government, utilising Microsoft System
Center Configuration Manager (SCCM), as well as providing OS delivery
solutions.

Software deployment was scripted using PowerShell, and ocassionally required
dropping down to manual WMI configuration using WSQL and C#.

### Notable Achievements

- Developed a new remote Operating System deployment front-end, with Windows Forms and
  .NET Framework 4.5, to register and configure SCCM device resources. This was
  rolled out to manage all NT Schools asset deployments.

- Developed a manager-focused web dashboard with Rust and Svelte, used to
  represent the active and historical status of HPSM ticket queues, separated
  by teams. This allowed managers to precisely track the timeline of their
  teams' performance, and report progress to stakeholders.

- Updated a 12-year-legacy interface to semi-automate and simplify the OS
  delivery process for ICT staff across the Norther Territory. This was the
  on-device asset configuration, where the other project was for remote
  deployments.
